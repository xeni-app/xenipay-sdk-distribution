# XeniPaySDK

Closed-source binary distribution of the XeniPay SDK for iOS.

## Installation

### Swift Package Manager

1. In Xcode, go to **File > Add Package Dependencies...**
2. Paste the repository URL:
   ```
   https://github.com/xeni-app/xenipay-sdk-distribution
   ```
3. Set the dependency rule to **Up to Next Major Version** starting at `1.0.0`.
4. Click **Add Package**.

## Requirements

- iOS 14.0+
- Xcode 15.0+
- Swift 5.9+
